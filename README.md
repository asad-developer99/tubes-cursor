# Tubes Cursor

A lightweight, interactive cursor effect built with vanilla **HTML, CSS, and JavaScript**. It replaces the default cursor with smooth, glowing tube-like trails that follow mouse movement, adding a modern, futuristic touch to any webpage.

![License](https://img.shields.io/github/license/asad-developer99/tubes-cursor)
![Stars](https://img.shields.io/github/stars/asad-developer99/tubes-cursor)

## ✨ Features

- 🎨 Glowing, animated tube/trail effect that follows the cursor
- ⚡ Built with plain HTML/CSS/JS — no heavy frameworks required
- 🖱️ Smooth, real-time response to mouse movement
- 🎯 Easy to drop into any existing web project
- 🪶 Minimal footprint, fast to load

## 📦 Getting Started

### Prerequisites

Nothing but a modern web browser — no build tools or package managers required.

### Installation

Clone the repository:

```bash
git clone https://github.com/asad-developer99/tubes-cursor.git
cd tubes-cursor
```

Then simply open `index.html` in your browser:

```bash
# macOS
open index.html

# Windows
start index.html

# Linux
xdg-open index.html
```

Or serve it locally for a smoother experience:

```bash
npx serve .
```

## 🎨 Customization

You can tweak the look and feel of the effect by editing a few key areas:

- **Colors & glow** — adjust the relevant CSS variables/rules in `style.css`
- **Trail length, speed & smoothness** — tune the animation parameters in `script.js`
- **Layout & content** — modify `index.html` to embed the effect in your own page

> 💡 Tip: This effect can be lifted out and dropped into any existing site — just include `style.css` and `script.js` and attach the cursor logic to your page.
